## 一、要回答的问题

本任务只收窄两个空格：

1. 照片转实体手办及相邻定制品中，用户自主编辑和设计师代办分别怎样被提供、使用或绕过；
2. 当前公开供给中，是否存在同一人物复制多件的明码报价、折扣或重复建模费说明。

用户自主编辑与设计师代办是竞争关系，不预设前者更先进。竞品存在自主调整功能，不证明用户需要；竞品不存在该功能，也不证明 PPSB 能做成或应当开发。

执行纪律：

5. 页面自述、可点击界面、实际完成的操作和后续计划必须分账。

流程记录字段：

| 字段 | 记录要求 |
|---|---|
| 输入入口 | 纯照片、到店扫描或无法判断 |
| 账号要求 | 是否登录，是否要求手机号或其他个人资料 |
| 预览出现时间 | 上传后、设计师处理后、付款前或付款后 |
| 预览形态 | 二维、三维、三百六十度旋转或无法判断 |
| 可调对象 | 发型、表情、五官比例、服装、姿势及其他实际可见项目 |

| 设计师依赖 | 是否必须等待人工处理，人工出现在哪一步 |
| 付款墙 | 哪一步开始要求付款；免费范围到哪里结束 |
| 生产衔接 | 用户调整结果是否明确进入最终生产版本 |
| 版本信息 | 页面地址、访问日期和可见版本信息 |
