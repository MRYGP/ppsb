# TASK-003｜赠礼版需求侧验证（接收者行为）

> 建立日期：2026-08-08
> 性质：需求侧任务，与 TASK-001、TASK-002 并行
> 状态：阶段 A 已于 2026-08-10 完成 R1 公开观察；阶段 B 待样品到手后启动；阶段 C 待另行授权
> 依据：decisions/2026-08-08-赠礼版的五角色结构.md
> 禁止：不做问卷、不问「你会不会买」、不用雇员、付费参与者与直接人情单充当独立需求证据

## 一、目标与边界

本任务只回答需求侧问题，不涉及成本与报价。

要回答的：
1. 付款人是否愿意为「送一个自己」实际付款；
2. 接收者是否愿意接受；
3. 接收者是否愿意摆放、保留、并在一段时间后仍摆放。
4. H6：同一人物复制 N 件时，复制数量、每件价、订单总价、逐位接收者和长期接触者如何影响付款、接收与摆放。

明确不承担：复制件成本、供应商报价、工艺可行性（属 TASK-002）。

本任务可使用付费共创参与者压力测试全流程摩擦，分为第一波与第二波，见 decisions/2026-08-09-三波验证结构与参与者边界.md。参与报酬、免费样品或直接人情关系会使结果不能作为独立付款需求，相关结果须单列为产品体验证据。原「研究助理」角色已取消，其记录职责当前无固定承担人。

## 二、纪律（本任务的全部价值取决于这一节）

- 意愿不是行为。「我觉得挺好」「以后可能会买」一律不计入证据；
- 雇员、直接人情关系、免费收样者的行为不计入自然需求；
- 免费赠送产生的摆放行为，与付费购买后产生的摆放行为，
  必须分开记录，不得互相替代；
- 主动行为权重高于被问答复：接收者主动拍照、主动提及、
  主动询问「我也想做」，价值高于回答「我很喜欢」。
- 被观察本身会污染结果。知道自己正在被跟踪的接收者，
  其摆放行为不能等同于自然摆放。跟踪须尽量降低提示性，
  且必须记录接收者是否知情。
- 付款与摆放不可互相替代。只有付款是 `F-M`；
  接收、摆放、两周后仍在原位都是并列行为事实。

## 三、阶段 A｜零成本观察（现在即可执行）

> 本阶段全部产出的等级上限为 `I`（线索）。公开晒单不能证明
> 付款、赠礼关系或长期摆放：晒单者可能是自己买自己，
> 可能是商家安排，可能只晒开箱不代表长期摆放。
> 阶段 A 的作用是收窄观察方向，不是提供证据。

在公开平台观察现有同类产品的接收者行为，不接触任何人：
1. 搜索真人定制手办、来图定制人偶的晒单，区分「自己买自己」
   与「收到别人送的」两类，分别计数；
2. 记录晒单中是否出现摆放位置（桌面、书架、车内、抽屉）；
3. 记录是否出现「我也想做一个送人」这类接收者转买家的痕迹；
4. 记录负面反馈中与接收者相关的部分（不想摆、觉得奇怪、收起来了）。
5. 记录晒单图中人偶或底座是否带文字标识；若带，区分共同标识（时间、宿舍号、队名一类）与个人化私语；无法判断写「未知」。
6. 若后续执行 R2，记录原始晒单中是否明确出现同组多人各自制作自己的形象并互相交换。仅看到多个不同人物同时摆放而无法确认制作与交换关系时，写「未知」。本项未纳入已经完成的 R1，不得回填。
7. 若后续执行 R2，观察日常关系中被长期保存或公开陈列的形象主体，分列本人单人形象、他人单人形象、双方合影、群体合影与未知。材料可包括数字头像、大头贴、拍立得、桌面或宿舍相框、同学录与同类公开原页。
8. R2 必须区分「保存」与「公开陈列」。仅说明留存、收藏或放在相册中，不能写成长期摆在桌面；仅有一次晒单，也不能写成长期陈列。
9. R2 只记录原页可见行为与用户主动表述，不根据头像或照片内容推断心理动机。商家营销页、搜索摘要、媒体转述和无法回源内容不计入有效观察；页面需要登录或无法回源时写「待回源」。

阶段 A 全部为公开观察，无需授权，无成本。

默认承担人为当轮执行 agent，不再等待招募岗位到位。每轮设不超过两小时的时间盒，按原始页面逐条登记；遇到登录墙、反爬或原页不可访问时写“待回源”。时间盒结束时仍有空格不视为执行失败，不得为了填满表格改用商家营销稿或搜索摘要冒充用户行为。

R1 已落盘：`research/market/2026-08-10-PPSB-TASK-003阶段A公开观察-R1.md`。R1 找到即时正负反应与一条实际可见位置自述，但长期摆放、共同标识、同一人物复制 N 件的逐位接收者行为仍无材料。

## 四、阶段 B｜样品送出后的跟踪（待 TASK-002 样品到手）

样品是现成的观察机会，不额外花钱：

| 时点 | 记录内容 |
|---|---|
| 样品完成、送出前 | 制作人实物验收：是否认可实体，是否愿意自留一件，是否决定送出、要求返工或停止送出；只记录其主动说明的原因 |
| 交付当场 | 第一反应；有无主动拍照；有无主动提及 |
| 第 3 天 | 在哪里（桌面、书架、抽屉、不知道） |
| 第 2 周 | 是否仍在原位；位置是否变化 |
| 第 2 月 | 是否仍在原位；是否被提及过 |

制作人对本人成品的实物验收，是送出前的流程闸门，不是新增独立接收者角色。其认可、自留、返工或停止送出只构成 F-P 流程与产品体验事实，不替代接收者的接受、摆放或任何付款证据。

注意：本阶段的接收者是熟人且样品免费，按第二节纪律，
其摆放行为只能作为线索，不能作为自然需求证据。
真实证据须来自付费客户的接收者。
免费加熟人加知情被观察，三重污染同时存在。
本阶段结果只能用于改进跟踪方法本身，不得计入任何需求结论。

本阶段不额外花钱。需要花钱的流程压力测试见阶段 B2。

## 四之二、阶段 B2｜流程压力测试（待杨授权）

本阶段测的是流程，不是人群。任何参与者都不构成任何人群的审美样本，结果不得表述为「年轻用户接受度」或任何人群结论。

本阶段拆为两波，两波不得互相冒充。参与者与接收者均须年满 18 周岁。

### B2-1｜第一波：设计共创样品

参与者：一名设计背景、对人偶手办有兴趣的付费共创参与者。

要回答：造型语言、礼物感、头身比例与细节，以及她如何形成是否送出的决定并如实记录。

不能回答：普通用户是否好用、是否有人愿意付款、任何人群偏好。

第一波参与者具有设计背景。她能主动使用比例、气质、表情、风格等词汇，或能把审美判断写得具体，只能证明该参与者具备相应设计表达能力，不能证明普通用户也能定义“心中的自己”。该项不得从第一波升级为普通用户自主表达成立，须留待第二波或独立客户流程判读。

做法：她在单独知情同意后制作自己的形象样品。她是本人成品的第一实物验收者，而非新增独立接收者角色。样品完成后，记录她是否认可实体、是否愿意自留一件、是否决定送出、要求返工或停止送出；原因只记录其主动说明的内容。是否送出由她在看到样品后决定。不送出不影响报酬与岗位考核，也不影响第二波岗位延续。不得以岗位延续、报酬、考核或第二波机会推动其送出。若不送出，记为未通过送出前的制作人实物验收闸门，不等同于接收者拒绝；本波仍可形成造型标准和流程材料，但不产生接收者数据，不得写成接收者验证已经完成。若她自愿送出，件数由她决定，并按本节既有纪律跟踪接收者。若因反馈良好而追加，追加是她本人的决定，不计为需求信号。

第二波中的角色是手工设计执行者，与第一波样品是否送出无关。第一波未送出不阻止其承担第二波，但第二波仍须满足自身授权、客户招募、报酬和样品闸门。

证据不对称，读结果前必须默念：她经过岗位条件与自我选择，天然偏向对本产品友好的一端；若其自愿送出，她与接收者也属于最有利于本产品的圈层。她们说尴尬、不愿留、收进抽屉，是流程风险信号；她们说喜欢、摆出来，是弱信号。求职、面试与在岗期间的表述均不进入需求证据账；本波任何结果不得外推为人群结论，也不得计为需求。

产出：可送人的样品，以及一份写下来的审美标准（哪些造型决定是对的，为什么）。等级为 F-P 个案。

### B2-2｜第二波：手工流程压力测试

客户：从公开网络社区招募的普通人，非设计背景、无手办习惯，且不属于杨或第一波参与者的亲属、同学、直接人情关系。人数当前不设定。

执行者：第一波参与者可担任手工设计执行者。她不是本波的被测对象。

要回答：照片准备、风格选择、说不像、修改沟通的真实摩擦在哪里。

不能回答：需求、付款意愿、规模化工时基线。

本波跑完整流程，含实体制作、送出与后续反馈，不停在预览确认。

必须承认的偏误：执行者的解读能力高于普通人，投入动机强，会主动补位；同时她的执行速度低于熟练工。三者叠加，本波的工时、成本与成品质量全部标「参考区间，非判定线」。本波最有价值的产出是设计决策日志，不是成品。

设计决策日志：每一次修改逐条登记，五列。

| 列 | 记录要求 |
|---|---|
| 客户原话 | 原话或近似原话，不得改写为设计术语 |
| 执行者理解 | 她据此理解了什么 |
| 实际改动 | 她实际改了什么 |
| 决策来源 | 三选一：直接要求；基于照片推断；执行者审美偏好 |
| 对识别度的影响 | 该决定对「像不像」的影响：正向、负向或无 |

「基于照片推断」与「执行者审美偏好」两类，是客户没有说出而由执行者补上的部分。这两类的具体内容与关键程度，是未来 AI、模板与交互需要接住的原始材料。不按条数计量：一个关键判断可能比十个小判断更重要，须记录其对识别度的影响，不得只统计数量。

日志由执行者登记，由杨判读。执行者不评判自己的产出。

候选变体自然提出记录：若参与者在未被提示的情况下，自发提出「每人做一个、互相交换」或同义方案，记录原话、提出者角色、提出时机、人物数量与预期交换方式。不得主动询问、暗示或把互换作为默认选项。未自然得知时写「未知」。

接收者跟踪，B2-1 与 B2-2 共用：

| 时点 | 记录方式 |
|---|---|
| 送出当场 | 记录第一反应，并标注接收者是否事先知情 |
| 第 3 天 | 不主动询问，只记参与者自然得知的信息；未得知写「未知」 |
| 第 14 天 | 同上 |
| 送出物的底座标识状态 | 有共同标识、无标识或未知；不得因未得知而补问 |
| 接收者对像不像的自发评价 | 像、不像或未知；只记自发评价，不得诱导提问 |

不要求接收者拍照、摆放、好评或参与。不为填满表格而补问。本跟踪全部字段等级上限为 I，不进入任何需求结论。

报酬与成本：第一波参与者的报酬档与第二波客户的单次固定劳务费分列。样品生产、物流、沟通与修改工时单列，不混入 TASK-002 的杨本人复制成本，也不写成独立客户订单单位经济。

闸门：第一波样品交付且设计决策日志锁定，即可开启 B2-2，不以第 14 天的接收者跟踪为前置条件。

本阶段全部产出等级上限为 F-P 个案或 I，不得升级为 F-M。

## 五、阶段 C｜付费验证（待杨另行授权）

阶段 C 拆为 C0 与 C1，两者不得合并计数。预算总框架不自动授权本阶段的对外报价、收款或交付承诺。

### C0｜透明预售存在性测试

在 PPSB 自有工艺样品完成前，可以向非雇员、非直接人情关系的独立客户展示数字预览，并可同时展示竞品实物作为尺寸与工艺参照。必须逐次明示：竞品实物不是 PPSB 成品，PPSB 实物尚未成型，最终材质、颜色、细节与参照物可能不同。

收取的只能是可全额退还的预售意向金，不使用“定金”作为未经法律确认的合同称谓。报价前须写清拟交付物、数量、预计交付日期、退款条件与尚未确定的工艺项。该付款单列为 `F-M（可退预售意向金）`，不得与看过 PPSB 自有样品后的成品订单付款合并。退款、拒付和未开口报价同样进入记录。C0 启动前另行确认收款主体、页面披露与退款约定；本任务不作法律结论。

竞品实物不能替代 PPSB 样品，不能用于承诺 PPSB 的成品质量，也不能进入 C1。

### C1｜自有样品后的成品付款测试

向非雇员、非直接人情关系的独立客户展示 PPSB 自有工艺样品与明确价格，观察是否付定金或全款；若成交，按第四节表格跟踪其接收者。只有本层可以解释为客户看过 PPSB 实物参照后的付款。

阶段 C 的每次接触先强制登记以下字段，再记录结果：

| 字段 | 记录要求 |
|---|---|
| 验证层级 | C0 透明预售或 C1 自有样品，不得留空 |
| 付款人是否等于接收者 | 是或否，不能留空 |
| 发起人 | 是否与付款人相同 |
| 摆放决定者 | 是否与接收者相同 |
| 接收者是否事先知情 | 是、否或未知 |
| 展示物 | C0 分列数字预览与竞品参考实物，并记录两项免责声明；C1 只能登记 PPSB 自有工艺样品 |
| 场景 | 毕业、日常关系或其他，逐笔标注，不得合并计数 |
| 形象主体与赠礼语义 | 三选一并写明人物关系：制作人本人，对应“把我留给你”；接收者本人，对应“把你做成礼物”；双方或群体，对应“把我们留下来”。无法判断时写未知，不得用一种语义的结果代表另外两种 |
| 产品单位 | 人物数量与复制件数分开登记。当前基线为 10cm 以内、Q版、单人、全彩、素色底座；若为同一人物复制 N 件，须登记 N；若对方自发提出多人各自制作并互换，另记参与人数、独立模型数、每个模型件数与提出时机，不得主动诱导 |
| 付款人实物验收 | C0 写不适用。C1 记录付款人是否在送出前看到本人最终实体；若看到，记接受、要求返工、停止送出或未知。是否自留一件另记有、无或未知。本字段只记交付流程，不替代接收者接受、摆放或付款 |
| 底座标识 | 有共同标识、无标识或未知 |
| N 与价格 | 复制数量、每件报价、订单总价、物流与修改是否含入 |
| 接收者清单 | 用脱敏编号逐一登记，不写真实姓名 |
| 分送方式 | 当面、寄送或转交，以及谁实际接收 |
| 长期接触者 | 接收者之外，日常同处一个空间的室友、同事或家人；若未知则写未知 |
| 报价与交期 | 一次报全价和明确日历日期，写明修改与超期处理 |
| 付款节点 | 全款预付，或开工前定金；不把货到付款计作同等付款证据 |

拒绝、未开口报价即结束和成交都必须进入同一张拒绝记录表。每条至少记录：接触日期、关系场景、是否看到实物、卡住步骤、原话或近似原话、是否提出替代条件，以及付款人与接收者的关系。若涉及同一人物复制 N 件，还须记录 N、每件价、订单总价和分送方式。若对方自发提出多人各自制作并互换，按产品单位字段登记，不得追问意愿来补齐记录。拒绝记录用于判断当前产品单位、价格、展示物或接触渠道哪个变量应被替换，不用于给需求打分。

成交后的接收者跟踪须逐位记录，不得用一位接收者的接受、摆放或拒收代表整笔 N 件订单。长期接触者的反应只作行为事实或 I 线索，不替代接收者行为，更不替代付款。

阶段 C0 与 C1 均需杨分别明确授权，不在本任务自动执行。
