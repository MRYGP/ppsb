# TASK-001｜当前供给核验与 Q 版三档询价

> 建立日期：2026-08-06  
> 当前状态：阶段 A 已完成；阶段 B 等杨明确授权  
> 禁止：无边界竞品扫描、直接采购、直接联系商家、把页面当成交、用单一价格比值宣布成本黑洞

## 一、任务目标

回答两个问题：

1. 当前有哪些“真人照片与身份线索输入 → 统一卡通角色 → 实物交付”的真实公开供给；
2. 单人、四个单人和四人一体三种产品单位的报价差，分别来自按脸处理、多人构图、生产、包装还是返工责任。

本任务不证明需求，不做最终投资判断。

## 二、阶段 A｜公开核验与询价包准备

阶段 A 不联系任何商家，不登录私人账号，不下单。

### A1. 供给账本

候选上限为 5 家，是工作量上限，不是成功门槛。不足 5 家不补数。

优先核验：

- 当前可访问的京东、淘宝或独立站真人卡通公仔／Q 版来图定制商家；
- 支持统一角色风格、多人组合和数字预览确认的供给者；
- 五彩石／易模只作为中国生产、报价和流程参照，不作为产品定位对标。

到店扫描链路、只生成图片／模型不交付实物的工具，另表记录，不进入五档报价比较。

### A2. 第一轮产品定义与风格

第一轮只询 **真人原型的卡通角色／Q 版**，不询写实复刻。

产品验收口径：

- 一组人物必须保持统一的比例、线条、材质与配色风格；
- 每个人通过发型、眼镜、脸部特征、服装、姿势或一个标志性物件保持身份可识别；
- 熟人能认出是谁即可，不要求皮肤纹理或一比一面部结构；
- 用户先确认数字角色稿，再进入实体生产。

原因：PPSB 当前要验证的是多人关系构图和群体交付，不是高写实肖像还原。写实会把相似度、毛发、肤色与手工上色返工混入主线成本。

照片卡通化本身不再作为本任务的核心技术问题；本任务要核的是同一套角色设计能否稳定进入实体、多人是否增加人工与返工，以及供应商能否按统一风格交付。

如果供应商不支持 Q 版，记录为“不匹配”，不要求其按写实替代报价。

### A3. 五档产品单位（按优先级排列）

| 档 | 产品单位 | 优先级 | 主要测什么 |
|---|---|---|---|
| A  | 1 人、1 件单人人偶 | 基线 | 首次建立一个人物的总成本 |
| B  | 同一订单 4 人、4 件独立单人人偶 | **核心** | 每增加一个新身份的成本；核心产品单位报价 |
| A2 | 同一人物、复制 4 件完全相同成品 | 高 | 分离"建模成本"与"生产复制成本" |
| D' | 同一人物、同一批照片，做两个不同风格版本 | **高** | 身份线索提取是否可复用；第二次付款是否有规模奖励 |
| C  | 4 人组成 1 件群体作品，共享底座 | 诊断 | 多人构图是否单独计价 |

档位表依据杨 2026-08-06 对话决策（F-P）：第二次购买的对象是同一人物的不同人格版本（如智者版、二次元版），而非同一角色换服装/动作；换装与配件变化因供应链复杂而推迟，关系组合（多人共享底座）不作为核心——用户到手的是单独个体。

档 D' 规格：同一人的同一批照片，先做 1 件写实卡通版，再做 1 件明显不同风格版（如二次元版）。两件均为单人、约 10cm、独立底座。必须问：第二件是否仍收全额建模费，还是只收风格化/重塑费。

各档的人物造型、服装和风格保持一致（D' 的两个版本除外——后者刻意要求不同风格）。同一商家的五档一起询问，不能拆给不同商家后横向拼接。

### A4. 固定规格

| 项目 | 第一轮规格 |
|---|---|
| 人物风格 | 真人原型卡通角色／Q版；同组统一比例、线条、材质与配色；毕业服，简单站姿 |
| 人物高度 | 每个人物约 10cm；档 C 保持人物高度，不以缩小人物偷换成本 |
| 输入 | 每人 3—5 张清晰照片，纯照片输入，不到店扫描 |
| 身份线索 | 每人至少保留 2—3 个可识别线索，例如发型／眼镜／脸部特征＋服装／姿势／标志性物件；具体线索在询价样例中固定 |
| 配件 | 除事先选定的身份标志物外，不含复杂道具；毕业帽和毕业服计入基础规格 |
| 文字 | 无刻字 |
| 修改 | 报价需明确包含的免费修改轮次 |
| 收货 | 同一湘潭地址，普通交期，不加急 |
| 材料／上色 | 不预先假定某种工艺；要求同一商家五档使用同一材料和上色方式，并逐项写明 |
| 底座 | A/B 为相同独立素色底座；C 为共享素色底座，要求单列底座尺寸、材料与价格 |
| 包装 | A 单独包装；B 四个内盒＋一个外箱；C 一个适配群体作品的包装。包装费必须单列，不与产品成本混算 |

不同商家的材料和工艺可以不同，但同一商家的五档必须一致；跨商家比较时按工艺分组，不把不同材料的价格直接排名。

### A5. 必问字段

每档分别记录：

1. 总价与含税／含运费口径；
2. 按脸建模与修型是否单列；
3. 每增加一人的追加报价；
4. 档 C 是否收多人姿态／站位／关系构图费；
5. 生产材料、打印、后处理和上色费用；
6. 底座、拼装和包装费用；
7. 下单到发货的交期；
8. 免费修改轮次、超出后的单轮价格与时间；
9. 照片不合格的判断和退款处理；
10. “不像”、色差、破损、返工与运输责任；
11. 是否能提供已脱敏的毕业班级、宿舍、实验室或企业团队案例；
12. 是否接受先做一件样品。
13. 数字预览确认后，实体若丢失已约定的发型、眼镜、服装、姿势或标志物，如何判定和返工；
14. 同一人物的同一批照片，若要制作第二个明显不同的风格版本，建模费用是否可以减免？减免比例是多少？贵方是否会保存已确认的人物数据供后续使用？保存多久？
15. 同一人物复制多件完全相同的成品，第 2 件起的单件价格是多少？与制作不同人物相比，差额主要发生在哪个环节？

### A6. 解释纪律

- 不用 `档C总价 ÷ 档B总价` 单独宣布成本黑洞；
- 共享底座可能降低成本，体积、支撑和包装可能提高成本；
- 必须结合商家对建模、构图、生产、底座、包装和返工的分项解释；
- 报价是供给行为，不是客户付款；
- “能把照片卡通化”只是基础能力，不等于该供应商能稳定交付统一风格的多人实体；
- 没有商家能做档 C，只能说明当前供给能力或检索范围存在空格，不能证明需求不存在；
- 商家说“做过很多”不算成交证据，需记录可核实边界；
- 供应商说“可以保存模型”只是能力自述，不等于实际减价；必须要求其给出第二版本的具体报价数字，而不是“可以商量”。

### A7. 本轮不询问的事项（防止范围蔓延）

以下不进入本轮询价，避免后续误以为已测：

- 服装、配件、道具的变体报价（杨已决定推迟，供应链复杂）；
- 数字交付物（头像、表情包）的报价；
- 批量（>10 件）阶梯价；
- 海外供应商（是否纳入由杨在阶段 B 授权时裁决）。
