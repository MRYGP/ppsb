# TASK-004｜数字流程自测（内部流程，非供应商）

日期：2026-08-09  
性质：内部数字流程工时与身份线索保持的核验；与 TASK-002 分账。  
状态：待杨授权。  
禁止：不联系供应商、不下实体单、不使用未经杨授权的付费订阅或生成积分、不把数字效果图当作实体样品或需求证据。

## 一、与 TASK-002 的边界

| 项目 | TASK-002 | TASK-004 |
| --- | --- | --- |
| 对象 | 外部供应商 | 内部数字流程 |
| 测量对象 | 实体复制件报价与质量 | 人工工时与身份线索保持 |
| 可能花费 | 样品费、打印费 | 软件订阅或生成积分 |

两者成本必须分账，不得合并计入任何单位经济。

## 二、本任务不是零成本

若需要订阅工具或购买生成积分，须杨单独授权并设定金额上限。不得因测试默认续订任何长期服务。

使用本机已有工具或已有免费额度时，才可以记录为“本次未额外花钱”；这不等于数字流程不存在工具成本。

## 三、记录项

| 环节 | 记录内容 |
| --- | --- |
| 照片到 Q 版效果图 | 耗时；尝试轮次；身份线索是否保留 |
| Q 版到三维模型 | 耗时；生成次数；失败原因 |
| 自动修复 | 耗时；覆盖的问题；未覆盖的问题 |
| 人工复核与修复 | 耗时；卡在什么问题；是否改变关键外观 |
| 修复后相似度 | 修完后是否仍可辨认出本人；丢失或变形的身份线索 |
| 头身接口拼装 | 耗时；是否需要人工调整；接口问题 |
| 导出与打印前检查 | 文件是否可用；封闭性、壁厚、细部和支撑风险 |

“人工复核与修复”及“修复后相似度”是本任务的关键记录项。几何合格不等于仍像本人。

## 四、实验设计

固定同一组照片、同一 Q 版目标、同一尺寸和同一身体模板。只比较两条候选工具链，不做大范围工具横评。

本仓不推荐固定技术栈。外部讨论中出现的工具名称、价格、通过率和覆盖率，如无可复核的一手来源，均为 Ø。

照片只可使用杨本人或已获得明确授权的对象。原始照片和含可识别肖像的中间文件不得进入公开仓。

## 五、验收与后续

本任务不预设工时、成本或相似度阈值。完成少量可比记录后，再由杨决定是否建立后续判据、是否继续订阅工具或是否进入实体样品阶段。

任务结果只回答内部数字流程的可行性问题，不裁决供应商成本、需求、付款意愿、渠道或商业成立。
