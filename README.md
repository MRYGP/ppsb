## 一句话定位

> 把一段关系，做成能摆在桌上的实体。

PPSB 研究的是：用户不必掌握专业设计，可在 PPSB 设计的身体、底座与整体风格中选择，并围绕照片生成的头部参与微调和确认；目标流程由模板、AI 与柔性生产把个人或群体关系变成可交付实物。

这仍是待验证的商业假设，不代表需求、价格、毛利、渠道或规模已经成立。

## 证据等级

| 标签 | 含义 |
|---|---|
| `F-M` | 真实市场行为：独立付款、续购、采购或承担明确成本 |
| `F-P` | 项目内部事实：已有文件、样稿、计划或内部动作 |
| `I` | 有依据但尚未被市场行为证明的推断 |
| `H` | 待验证假设 |
| `Ø` | 当前没有材料 |

只有 `F-M` 可以对商业成立产生强加分。项目内部定价、员工行为、免费赠送、朋友支持、融资、用户数和页面存在都不能代替独立付款。
