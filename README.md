# PPSB｜AI关系实体化／毕业人偶研究库

> 当前状态：研究候选，尚未完成公司立项或投资决策  
> 建库日期：2026-08-06

## 一句话定位

> 把一段关系，做成能摆在桌上的实体。

PPSB 研究的是：用户不必掌握专业设计，只负责提出构思、选择和审核；模板、AI、人工与柔性生产共同把个人或群体关系变成可交付实物。

这仍是待验证的商业假设，不代表需求、价格、毛利、渠道或规模已经成立。

## 默认读取顺序

1. `AGENTS.md`：仓库操作和证据规则；

## 证据等级

| 标签 | 含义 |
|---|---|
| `F-M` | 真实市场行为：独立付款、续购、采购或承担明确成本 |
| `F-P` | 项目内部事实：已有文件、样稿、计划或内部动作 |
| `I` | 有依据但尚未被市场行为证明的推断 |
| `H` | 待验证假设 |
| `Ø` | 当前没有材料 |

只有 `F-M` 可以对商业成立产生强加分。项目内部定价、员工行为、免费赠送、朋友支持、融资、用户数和页面存在都不能代替独立付款。

## 当前验证顺序

1. 核实至少一个直接竞品当前是否仍可购买；
2. 选定一种产品单位，完成一件真实样品；
3. 记录按脸和按订单的完整工时、成本、返工与质量；
4. 向独立客户提出明确交付、价格和付款节点；
5. 取得一次真实渠道行为，而不只是一句合作意向。

在这些证据回来前，不开发小程序，不扩模板库，不启动完整团队，不恢复融资与三年预测。
