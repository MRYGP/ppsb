## 三、怎么找到她们？三个触点

### 触点1：实验室大师姐（最关键）
- **角色**：即将毕业的研三/博三女生，通常是实验室"管家"
- **痛点**：组织谢师宴、准备导师礼物、给师弟师妹留纪念
- **话术**：不是"定制人偶"，是"给导师/实验室做一个**全家福实体**"——底座刻实验室名字，导师放中间，学生围一圈
- **转化点**：大师姐决策，全组AA，人均150-200

### 触点2：毕业季跟拍摄影师
- **场景**：4-5月实验室拍毕业合影
- **植入**：摄影师拍完照后推荐"除了照片，要不要做一个**立体的实验室全家福**？"
- **分佣**：摄影师推荐成功一单，返20%或固定50元/单

### 触点3：校园打印店（论文打印高峰期）
- **场景**：3-5月打印毕业论文，学生每天进出
- **展示**：打印店柜台放一个**实验室Q版人偶样品**+二维码
- **话术**："师姐她们实验室订的，答辩完送给导师"

## 四、第一单怎么打（MVP0）

**目标**：10天内，搞定**1个实验室（4-6人）**的免费样品，换取真实反馈。

| 天数         | 动作                                                         | 标准                             |
| ------------ | ------------------------------------------------------------ | -------------------------------- |
| **Day 1-2**  | 在小红书/豆瓣搜"毕业 实验室 谢师宴"，私信5个即将毕业的研三女生，提供免费样品 | 至少1人回复                      |
| **Day 3-5**  | 根据她提供的实验室合影，用AI生成Q版6人组，发给她确认         | 修改不超过2轮                    |
| **Day 6-8**  | 打印+涂装，寄出                                              | 成本控制在300元以内（全组）      |
| **Day 9-10** | 回访：是否送给导师？导师反应？是否晒图？同实验室其他人是否想订？ | **关键指标：同实验室追加订单数** |

**通过标准**：如果这1个免费样品带来**≥2个付费咨询**（同校其他实验室），滩头用户验证通过。

**止损线**：如果10天内找不到1个愿意配合的研三女生，或样品送出后零传播，说明"实验室"场景假说不成立，换本科女生宿舍再试。

## 四、从她们身上提取什么数据？

不是"她们干了多少活"，是**"她们暴露了什么真相"**。

| 数据类型       | 具体指标                         | 通过阈值                   | 失败信号             |
| -------------- | -------------------------------- | -------------------------- | -------------------- |
| **痛点真实性** | 她们自己愿不愿意买？             | 80%愿意自付                | "我觉得挺好但我不买" |
| **共创流畅度** | 从传照片到确认样稿，平均几轮？   | ≤2轮                       | ≥4轮，或放弃         |
| **群体传染性** | 同实验室追加订单数               | 1个助理带来≥2个实验室咨询  | 零传播               |
| **价格接受度** | 她们实验室的真实预算中位数       | 150-250元/人               | "超过100就不考虑了"  |
| **决策链长度** | 从"知道产品"到"决定买"需要几天？ | ≤3天                       | 讨论2周无结论        |
| **内容裂变力** | 晒图后自然咨询量                 | 每条晒图≥3条私信问"哪里订" | 点赞多但无人问       |
