## 毕业场景的结构性优势：N×M的乘数效应

你抓到了一个**被忽略的商业结构**。

婚礼是**单点决策**（一对新人，客单价高，但获客一次只锁2人）。毕业是**网络决策**——一个宿舍、一个班级、一个实验室，**决策发起者天然是销售节点**。

---

## 一、N个组合：从"单客"到"单群"的单位经济重构

| 组合类型                | 人数 | 定价策略           | 单群价值 | 获客效率                     |
| ----------------------- | ---- | ------------------ | -------- | ---------------------------- |
| **单人纪念**            | 1    | 199元              | 199元    | 低（个人决策慢）             |
| **情侣/闺蜜**           | 2    | 179元/人（略降）   | 358元    | 中                           |
| **宿舍（3-4人）**       | 4    | 149元/人（团购价） | 596元    | **高**（一人发起，三人跟单） |
| **小团体（5-8人）**     | 6    | 129元/人           | 774元    | **极高**                     |
| **班级合影（20-50人）** | 30   | 99元/人（批量价）  | 2970元   | **裂变级**                   |

**关键变化**：
- 婚礼场景：CAC（获客成本）必须被**单客**摊薄 → 不可能
- 毕业场景：CAC被**单群**摊薄 → **搞定1个班长，拿下30单**

**这不是复购，这是"单客裂变"**——同一个用户不会买两次，但同一个用户会拉4个室友一起买。

---

## 二、因子变化：模板不是"一套"，是"生成器"

你之前说的"每个因子可以变化"，意味着模板库不是静态的，是**参数化生成系统**。

| 因子维度 | 可选参数                                        | 用户感知               | 平台成本                 |
| -------- | ----------------------------------------------- | ---------------------- | ------------------------ |
| **人数** | 1/2/3/4/5/6/班级合影                            | "我们宿舍刚好4人"      | 同一套骨骼系统，缩放即可 |
| **服装** | 学位服（粉/灰/黄/红领）+ 内搭（衬衫/卫衣/旗袍） | "我们班是工科，黄领"   | 同一套服装模板，换色即可 |
| **姿势** | 抛帽/握手/搭肩/背影/跳跃/围坐                   | "我们选那个一起抛帽的" | 5-8套核心姿势，复用      |
| **道具** | 书本/笔记本电脑/篮球/吉他/实验器材              | "他天天抱着吉他"       | 小道具库，低多边形       |
| **底座** | 学校大门/校训石刻/日期/班级号/专业梗            | "底座刻我们班口号"     | 文字系统+3D地标库        |
| **风格** | Q版/半写实/像素风/国潮                          | "我要Q版，她要写实"    | 风格切换是渲染层，零成本 |

**乘数效应**：
- 8套姿势 × 5种服装色 × 6种人数组合 × 10种底座 = **2400种"独特"变体**
- 用户感知："这是为我们定制的"
- 平台成本：8+5+6+10 = **29个底层资产**

## 三、毕业场景的决策链：找到"关键节点"

| 角色                 | 影响力   | 决策权重 | 如何触达                     |
| -------------------- | -------- | -------- | ---------------------------- |
| **班长/团支书**      | 高       | 发起者   | 校园代理、班级群             |
| **宿舍长**           | 中       | 组织者   | 小红书"毕业礼物"关键词       |
| **摄影协会会长**     | 中       | 意见领袖 | 赞助合作                     |
| **毕业季跟拍摄影师** | **极高** | 信任背书 | **核心渠道：摄影师推荐分佣** |

**最关键的洞察**：
毕业季用户**不是先想到"买人偶"，是先想到"拍毕业照"**。摄影师在跟拍过程中，自然会说"除了照片，你们要不要做一个实体纪念？"

**渠道策略不是直接找学生，是嵌入已有的毕业产业链**：
- 摄影师推荐 → 分佣20%
- 校园打印店（打印论文/简历的地方） → 放样品
- 班级聚餐餐厅 → 桌牌/伴手礼

## 四、时间窗口：毕业季的"脉冲式"特征

| 时间节点 | 用户行为         | 平台动作                 |
| -------- | ---------------- | ------------------------ |
| **3月**  | 开始讨论毕业礼物 | 模板上线、校园代理招募   |
| **4月**  | 拍毕业照高峰期   | 摄影师渠道激活、样品植入 |
| **5月**  | 决策高峰期       | 团购优惠、班级拼单活动   |
| **6月**  | 交付deadline     | 产能爬坡、物流保障       |
| **7月**  | 晒图传播期       | 内容二次发酵、口碑沉淀   |

**脉冲式生意的生死线**：
- 必须在**4-5月**完成80%的订单锁定
- 6月不是销售期，是**交付地狱**（30天周期意味着5月订单6月交付，刚好赶上毕业）
- 7月的晒图决定**下一年**的自然流量基数

## 六、一个关键验证

毕业场景的N×M优势是**结构性**的，但必须验证一个假设：

> **"宿舍/班级"的群体购买，是"一人发起、众人跟单"，还是"众人讨论、无人决策"？**

| 结果                             | 含义                     | 对策                                 |
| -------------------------------- | ------------------------ | ------------------------------------ |
| 跟单型（1人发起，3人秒付）       | ✅ 群体效应成立，飞轮启动 | 重点培养"发起者"（班长/宿舍长）      |
| 讨论型（4人讨论2周，最后没人买） | ❌ 群体决策=决策瘫痪      | 必须改为"单人纪念"主推，群体作为增项 |

**验证动作**：Phase 0的10个免费样品，不要送给"个人"，送给**2个宿舍（8人）和1个班级（30人）**，观察：
- 是宿舍长/班长主动组织，还是无人问津？
- 是AA制分摊，还是一人垫付？
- 是收到后集体晒图，还是各自发各自的？
