## 不是"没人想到"，是**四条线从未同时跨过阈值**

之前所有玩家（记梦馆→速哇→mikibobo→易模）都卡在**单一变量突破、其他变量拖后腿**的结构性困境里。

---

## 一、技术线：AI生成3D的能力，2024年才跨过"可用"门槛

| 时间节点      | 技术状态                                            | 对项目的影响                                       |
| ------------- | --------------------------------------------------- | -------------------------------------------------- |
| **2013-2015** | 无AI，全靠手工雕塑/3D建模师                         | 记梦馆/品啦：人力成本极高，无法规模化              |
| **2018-2020** | 3D扫描仪成熟，但需专业影棚                          | 速哇：必须开线下店，重资产锁死                     |
| **2022-2023** | NeRF/ photogrammetry 可从照片重建，但精度差、修模重 | 易模：能跑通，但"手机拍摄→可用模型"仍需大量人工    |
| **2024至今**  | Tripo/Meshy等AI工具，照片→3D模型可用度大幅提升      | **你的窗口**：修模成本可能从"数小时"降到"数十分钟" |

**关键事实**：2024年之前，**"用户上传照片→AI生成可用3D模型"**这个环节不存在。要么用户到店扫描（速哇），要么寄照片给建模师手工做（淘宝）。你的"纯线上+AI直出"模式，技术上**去年才成为可能**。

---

## 二、成本线：3D打印的"仪式级"精度，成本刚降到心理线以下

| 精度要求                 | 2015年成本 | 2020年成本 | 2024年成本 | 用户心理线        |
| ------------------------ | ---------- | ---------- | ---------- | ----------------- |
| 全彩树脂打印（写实）     | 1000元+/个 | 300-500元  | 150-250元  | ❌ 仍太高          |
| 单色软胶+手工涂装（Q版） | 200元+/个  | 80-120元   | 30-60元    | ✅ 199元售价可覆盖 |

**之前没人做的核心原因**：即使有人想到了"模板+用户微调"的模式，**打印成本不支持199元定价**。

记梦馆卖1000元+，速哇靠规模把9cm压到199元（但那是极简Q版+批量模具），**你的"单件定制、AI适配、柔性生产"在2020年的成本结构下是数学不可能**。

---

## 三、供应链线："小批量柔性生产"直到2023年才不亏钱

| 生产模式     | 起订量    | 单件成本                          | 适用场景     |
| ------------ | --------- | --------------------------------- | ------------ |
| 钢模注塑     | 5000件+   | 5-15元                            | 泡泡玛特     |
| 硅胶翻模     | 100-500件 | 30-50元                           | 淘宝软陶定制 |
| 光固化3D打印 | 1件起     | 2015年:200元+ / 2024年:20-40元    | **你的场景** |
| 全彩喷射打印 | 1件起     | 2015年:1000元+ / 2024年:100-200元 | 速哇高端线   |

**关键变化**：光固化3D打印（LCD/MSLA）在2022-2024年经历了**设备国产化+树脂材料降价**，单件打印成本下降了约80%。

但注意：**打印成本降了，后处理（清洗、固化、打磨、涂装）的人工成本没降**。你的项目能不能跑通，取决于**AI能不能把"后处理"也干掉一部分**（比如生成更光滑的模型减少打磨）。

## 四、用户认知线："定制人偶"从"猎奇"到"仪式选项"的转变

| 阶段          | 用户认知                                    | 代表产品                  |
| ------------- | ------------------------------------------- | ------------------------- |
| **2013-2018** | "3D打印人偶？高科技玩具吧"                  | 记梦馆（科技猎奇）        |
| **2019-2022** | "商场里那个扫描做小人的，挺好玩"            | 速哇（体验式消费）        |
| **2023-2024** | "原来可以线上定制啊，毕业/结婚送这个挺特别" | 淘宝软陶+易模（场景渗透） |
| **2025+**     | "我的婚礼/毕业，应该有一个专属实体"         | **你的目标认知**          |

**之前没人做的社会原因**：用户脑子里没有"仪式人偶"这个品类。婚纱照、毕业照、纪念册是默认选项，人偶是"额外的"。

**现在为什么可能了**：
- 泡泡玛特培养了"人偶=情感载体"的认知（2020年上市，全民潮玩教育）
- 小红书/抖音的"定制礼物"内容把"专属感"打成了社交货币
- AI让"专属"不再等于"昂贵"

## 五、商业模式线：之前的玩家全部卡在"两端"，中间地带是真空

把之前的玩家画成光谱：

```
重资产 ←————————————————→ 纯线上
速哇      mikibobo      淘宝软陶      易模
(门店)    (设备加盟)    (手工C2C)    (纯线上)
  │           │            │           │
  │           │            │           │
  └───────────┴────────────┴───────────┘
              ↑
        【你的位置：AI+模板+仪式场景】
        这个位置之前不存在，因为：
        - 左边太重（速哇模式）
        - 右边太轻（易模模式，无场景无模板）
        - 中间太散（淘宝手工，不可规模化）
```

**真空地带形成的原因**：
- **太重**：速哇证明了线下能活，但无法扩张（租金绞索）
- **太轻**：易模证明了线上能跑，但无差异化（泛纪念，无场景，无溢价）
- **太散**：淘宝证明了需求存在，但手工产能锁死天花板

**你的模式试图填补这个真空**：比易模重（有模板、有场景、有仪式包装），比速哇轻（无门店、无扫描设备），比淘宝标准化（AI替代手工）。

## 六、一个残酷的补充：即使四条线都跨过了，"大规模"依然可能不成立

之前没人大规模做，还有一个**更深层的商业原因**：

> **仪式人偶是一个"高毛利、低频次、弱复购、高获客成本"的品类，天然不适合"大规模"，只适合"小而美"或"流量入口"。**

| 属性                | 对规模化的影响                  |
| ------------------- | ------------------------------- |
| 高毛利（60%+）      | ✅ 单件赚钱                      |
| 低频次（一生1-2次） | ❌ 无自然复购，必须持续买流量    |
| 弱复购              | ❌ 无法摊薄获客成本              |
| 高情感溢价          | ✅ 定价空间大                    |
| 高交付确定性要求    | ❌ 容错极低（婚礼搞砸=品牌死亡） |

**泡泡玛特能大规模**，是因为：
- 盲盒机制创造复购（收集成瘾）
- 标准化产品降低交付风险
- 社交货币属性带来自然裂变

**你的模式反着来**：
- 无复购（仪式一次性）
- 定制化带来交付风险
- 社交裂变依赖"晒图"，但晒图率不可控

**所以"大规模"可能从来不是正确目标**。之前没人大规模做，**可能是因为这个品类本身就不该大规模做**，而应该作为：
- 一个**高毛利的服务型生意**（年销1万单，净利100万+）
- 或一个**情感品牌的入口**（人偶→纪念日历→家庭档案→更多仪式服务）

## 一句话总结

> **2024年之前，技术不支持、成本不支持、供应链不支持、用户认知不支持——四条线全断。2024年之后，技术线刚接通，但成本线、供应链线、商业模式线依然紧绷。之前没人大规模做，不是因为笨，是因为"大规模"在这个品类里可能是个伪命题。**

你的真正问题不是"为什么之前没人做"，而是**"现在四条线接通了几条，够不够支撑一个可持续的生意"**。
