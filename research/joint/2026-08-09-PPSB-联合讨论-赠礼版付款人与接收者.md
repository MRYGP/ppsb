# PPSB 联合讨论｜赠礼版付款人与接收者

> 日期：2026-08-09
> 性质：持续讨论稿。外部页面和实验研究只能说明相邻机制或受控情境，不证明 PPSB 已有真实付款、接收、摆放或复购。
> 当前问题：付款人会不会为「把自己的形象送给他人」付款；接收者会如何接收、处理和摆放；怎样用一次独立试验把二者分开记录。

## 一、先拆成五个动作

赠礼版不是单一的「有人买了」：

| 动作 | 谁做 | 当前等级 | 不能由什么替代 |
|---|---|---|---|
| 提出制作 | 发起人 | Ø | 一句口头称赞 |
| 决定付款 | 付款人 | Ø | 免费样品、共创报酬或定金以外的承诺 |
| 接收实体 | 接收者 | Ø | 付款人对其反应的转述 |
| 决定摆放 | 摆放决定者 | Ø | 交付当场的礼貌 |
| 长期接触 | 接收者或同住者 | Ø | 一张开箱照片 |

只有独立付款是 F-M。其余是需要与付款并列记录的行为事实，不能用任一动作替代另一动作。

## 二、相邻活体：成熟玩家如何避免替人决定身份

Funko 的 Pop! Yourself 当前提供礼券：付款人买码并分发，接收者自己完成个性化设计。礼券可用于生日、里程碑和颁奖场景，并支持从一张到批量购买。Hero Forge 也提供由赠送者充值、接收者使用的礼品卡。

这两个例子只能证明付款人、设计者和接收者可以被产品机制拆开。它们没有证明某人愿意购买并复制自己的脸送给多人。恰恰相反，Funko 把最终身份选择权交回接收者，可能是在降低「收到别人替我决定的形象」的风险。后一判断是 I，不是 Funko 公布的原因。

来源：

- https://funko.com/pop-yourself-voucher/POP-YOURSELF-VOUCHER.html
- https://heroforge.com/content/product-information/about-products/gift-cards/

## 三、对「送一个自己」有利但有限的研究线索

一篇发表于 Journal of Experimental Social Psychology 的六项研究发现，在其所检验的赠礼情境中，反映赠送者自身特征的礼物会让赠送者和接收者报告更强的关系亲近感。另一篇 Journal of Consumer Psychology 论文研究了礼物与赠送者特征相符时的接收者评价。

这给 PPSB 的只是一个 H 级方向：把付款人自身作为礼物内容，可能有关系表达价值。它不能推出真人手办、陌生接收者、多个接收者、中国语境或长期摆放会成立。尤其不能把受控研究中的自报亲近感改写成支付或留存证据。

来源：

- https://www.sciencedirect.com/science/article/abs/pii/S0022103115000372
- https://myscp.onlinelibrary.wiley.com/doi/10.1016/j.jcps.2015.01.006

## 四、失败和风险线索

### 1. 定制品把风险压给付款人

Funko 当前将 Pop! Yourself 和定制品列为不可退换，礼券也标为最终销售。它说明成熟定制商会把返工和退换边界写得很硬，但不说明这种规则被用户广泛接受，也不说明 PPSB 可以直接照搬。

PPSB 的「像不像」风险比模板化的 Funko 更高。若用一次明确付款测试，应在付款前写明展示物、修改轮次、交期和「改两轮仍不像」的处理，而不是用不可退换掩盖风险。此处测试的是付款人是否愿意承担写清后的风险，不是测试其是否会被模糊承诺说服。

来源：https://funko.com/funko-returns-policy/funko-returns-policy.html

### 2. 自我实体化的停止不等于赠礼失败

Hasbro Selfie Series 曾允许用户将自己的脸放进既有 IP 角色，后停止新订单。停止事实只能说明强 IP 下的自我实体化产品也可能停止；公开材料没有给出其停止原因，且它不涉及把付款人形象赠给接收者。

因此不把它当作赠礼版的反证，也不把「未找到同位墓碑」写成市场空白。

来源：

- https://newsroom.hasbro.com/node/32341
- https://www.superherohype.com/geek-culture/557625-hasbro-discontinues-selfie-series-personalized-figures

## 五、当前工单有一处产品单位冲突

当前核心文件将「同一人物复制 N 件」列为唯一在验产品单位。但 TASK-003 阶段 C 的产品单位字段仍写为「10cm 以内、Q版、单人、全彩、素色底座」，没有要求登记复制数量、每件与总价、每位接收者或分送方式。

这会产生两种不同的试验：

| 试验单位 | 能回答 | 不能回答 |
|---|---|---|
| 单人单件赠礼 | 一名付款人是否愿意送出一件自己的形象 | N 件总价是否可承受，多位接收者如何分别处理 |
| 同一人物复制 N 件赠礼 | 一笔订单的总价、复制数量、接收者差异 | 单人单件是否存在不同的低门槛需求 |

二者都可以做，但必须分组，报价和结论不能合并。此处仅登记冲突，不改 TASK-003；是否将阶段 C 改为 N 件试验，须杨明确裁决。

## 六、一次合格试验的最小记录

如果杨以后授权阶段 C，记录应先于报价发生。为保持当前产品单位的可核验性，至少需要：

| 字段 | 要记录的事实 |
|---|---|
| 产品单位 | 单件，或同一人物复制 N 件，不能留空 |
| N 与价格 | 复制数量、每件报价、订单总价、物流与修改是否含入 |
| 付款人 | 是否独立于项目、是否实际付全款或定金 |
| 接收者清单 | 用脱敏编号逐一登记，不写真实姓名 |
| 是否事先知情 | 每位接收者分别记录是、否或未知 |
| 交付方式 | 当面、寄送或转交，以及谁实际接收 |
| 当场反应 | 原话或近似原话，有无主动拍照、提及或拒收 |
| 第三天、第二周、第二月 | 摆放、收起、转送、未回应及原因；明确是否为观察者主动询问 |
| 修改与售后 | 哪一方提出、耗时、实际承担成本 |

接收者可以不同意被跟踪。此时只记录其不同意，不设法从付款人处补听其私下反应，更不得因此扣减报酬或施压。公开仓只保存脱敏编号、日期和行为分类，肖像和联系资料留在私有记录。

## 七、最小推理与停止口径

当前无需预设付款率或摆放率，因没有可靠基线。第一次试验的价值是定位卡点：

- 面对实物和总价仍不付定金，暂停当前的产品单位、报价、展示物和接触渠道组合；
- 付款但接收者拒收或收起，暂停「赠礼版作为主推方向」，付款人侧与接收者侧分别保留结果；
- 接收者喜欢但付款人不付，不能用接收者评价替付款人补分，回到价格或付款人动机；
- 付款、接收和摆放均发生，也只形成一笔待复核闭环，不足以推出人群需求或增长模型。

## 八、暂不推出的结论

- 不写「赠礼天然比自购更有需求」；
- 不写「接收者会因关系而愿意摆放付款人的形象」；
- 不写「Funko 礼券证明 PPSB 的赠礼方向成立」；
- 不写「人格化礼物的实验研究证明有人会付款」；
- 不写「Hasbro 的停止证明这个方向不成立」。

下一步不是继续扩写场景，而是在杨授权、实物样品与完整报价都齐备后，选择其中一个产品单位做一次独立付款测试。此前的公开观察和付费共创参与者仍只能提供线索与流程改动。
