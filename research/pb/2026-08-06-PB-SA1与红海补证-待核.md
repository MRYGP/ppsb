## 三、标准询价规格草案（只起草，不联系商家）

**统一规格（三档共用，任何一项不同即报价不可比）**

| 项     | 固定值                                                       |
| ------ | ------------------------------------------------------------ |
| 尺寸   | 单人像高 12cm（站姿，含底座总高 ≤14cm）                      |
| 材质   | 光敏树脂，全彩一体成型                                       |
| 风格   | 写实（非 Q 版），如不支持写实则记为"该档不可比"              |
| 上色   | 全彩打印一体，不另加手工补色；若必须手工补色，单列该项工时与费用 |
| 底座   | 含，统一素色，无刻字                                         |
| 包装   | 单盒，含防震；三档同规格                                     |
| 收货地 | 同一城市同一地址                                             |
| 输入   | 仅提供照片（不到店、不扫描）；每人 3—5 张清晰全身照          |

**三档（同一批询价里必须三档一起问，否则拿不到对比）**

- **档 A**：单人一件。
- **档 B**：同一订单做 **4 个单人人偶**（4 个独立摆件，元素一致）。
- **档 C**：4 个人组成 **1 件群体作品**（同一底座、有站位关系）。

**必问九项（逐档分别问，不接受"差不多"）**

1. 总价；**按脸单价**（总价÷人数），三档分别给。
2. 交期（下单→发货，工作日）。
3. **含几轮人工修改**；超出后每轮收费与耗时。
4. **多人构图是否额外收费**——档 C 相对档 B 的差价属于哪一项：建模／构图／打印／人工。**这一问是全案的关键。**
5. 照片不合格如何处理：谁判定、是否退款、是否要求补拍。
6. 返工责任：像不像谁说了算，返工上限几次，运费谁承担。
7. 破损责任：运输破损、到货破损的赔付口径。
8. 退款：未发货前／已建模后／已打印后，三个节点分别退多少。
9. 是否接受**不到店、纯照片**输入；不接受则该商家整体记为"不同链路"，不进对比表。

**回收后只填三个数**：`档C总价 ÷ 档B总价`、`档C按脸价 ÷ 档A按脸价`、`档C交期 − 档B交期`。 若第一项 ≈1.0，说明多人一件只是把单人相加，**SA-1' 被削弱**；若显著 >1.0 且差价落在"建模／构图"项，**成本黑洞第一次有了坐标**。

> 建议至少覆盖 5 家、且必须包含五彩石（照片链路）与一家京东写实商家（照片链路）。**不含速哇等到店扫描链路**——那是另一条工作，混入会污染对比。
