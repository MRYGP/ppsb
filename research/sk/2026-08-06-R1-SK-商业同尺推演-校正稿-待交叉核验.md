# 五、对 PB 三档询价方案的技术与商业校正

> 以下在**未直读原方案**条件下作答，仅依据本提示词描述的档 A／B／C 与"共享底座、包装、体积、打印材料"字段结构。原文到手后须复核。

**1. 写实风格是否偏离 PPSB 当前假设**

偏离，而且是成本曲线层面的偏离，不只是审美偏好。写实要求人脸相似度、皮肤与毛发细节，成本集中在高精度打印＋手工上色＋"不像"引发的返工；Q版／风格化靠夸张吸收相似度误差，**返工触发条件结构上更少**。若 PPSB 当前产品假设是 Q版／风格化，按写实询价得到的报价既高估主线成本，又答非所问，还会把"成本黑洞是否存在"这个判断污染成不可读。

**2. 固定写实、固定 Q版，还是分两轮**

**分两轮，但不是平行两轮，是有序两轮。**

- 第一轮：**只按 PPSB 当前产品假设（Q版／风格化）询价**，得到主线成本。
- 第二轮：写实作为对照，**仅在主线报价回来后**、且需要测"相似度要求 → 成本"这条斜率时才做。

理由：一次问两种风格，供应商会给一个折中报价或按最贵的口径报，两个数都不准；且先问写实会把锚定价拉高，反过来污染第一轮。

**3. 档C总价／档B总价能否识别多人构图成本**

**不能。** 两档总价之差里至少混了四个变量：人数、体积、材料、底座与包装形态。除非其余三项被逐字固定，否则这个比值是噪音，不是信号。

要识别多人构图成本，唯一可靠做法是**同规格单变量对照**：同材质、同高度、同底座形态、同上色方式、同包装单位，只变人数（1 人／3 人／5 人），要求供应商给阶梯报价。

**4. 共享底座、包装、体积、打印材料造成的混淆**

| 变量         | 混淆机制                                                     |
| ------------ | ------------------------------------------------------------ |
| **共享底座** | 把 N 个人的一部分成本从"按脸"移到"按订单"，人为压低按脸边际——**直接伪造"多人更划算"的结论**，而这正是形态 A"一件群体作品"最需要验证的那一格 |
| **体积**     | 与成本强非线性：耗材量近似随体积三次方、打印时长随高度线性、支撑与后处理随复杂度非线性。不锁死尺寸，任何跨档比较都无效 |
| **包装**     | 按件包装还是按单包装，会直接翻转"每人一件"与"一件群体作品"的相对经济性。这一项目前最容易被漏掉 |
| **打印材料** | 光敏树脂／尼龙／全彩砂岩决定**是否需要手工上色**，而上色是按脸人工的最大变量。材料不固定，等于按脸成本不可读 |

**5. 必须增加的字段（按五类成本分离）**

- **按脸**：单人建模／修型工时；单人上色工时；每增加 1 人的追加报价（阶梯，非总价）
- **多人构图**：组合姿态设计费是否单列；底座尺寸随人数变化表；拼装与装配工时
- **生产材料**：材质单价（元／克或元／cm³）；单件耗材量；后处理（打磨／上色／UV）是否含在报价内
- **沟通修改**：含几轮免费修改；超出后单轮计价；单轮平均延迟
- **返工风险**：不像／色差／破损的判定权归谁；重做是否收费；供应商历史返工率；运输破损责任方

另加一条强制项：**所有档位按同一份规格书报价**，规格书固定材质／高度／人数／底座是否共享／上色方式／包装单位／收货地／修改轮次／返工责任。规格不同的报价不得横向比较——这是 PPSB v0.2 自己已经写下的纪律，询价方案必须继承它。

**最后**：照收"不得用一个价格比值直接宣布成本黑洞成立或不存在"。任何单一比值只能生成一个待验假设，不能生成结论。

**有依赖链（顺序不可颠倒）**

```
选定唯一产品单位 → 写死规格书 → 标准询价（先Q版一轮）→ 实物样品
```

- **标准询价**依赖规格书；规格书依赖产品单位选定。跳过这一步的询价会拿回一堆不可比的数字。
- **实物样品**依赖询价结果（否则不知按什么规格下单）。
- **独立付款**依赖"有可展示的交付承诺"，但**不必然依赖自制样品**——可以先用**竞品实物**＋明确规格、价格、交期的一页材料做付费意愿测试。这条路更便宜，且能把"独立付款"从依赖链末端提前。

**给出的建议顺序**：竞品核验与渠道行为并行起跑；同期由杨选定唯一产品单位并写死规格书；询价在规格书之后；样品在询价之后；独立付款测试可在竞品实物到手后即启，不等自制样品。
