# 一、两套单位经济模型

分项定义（每单）：`P` 客户支付 ｜ `V` 角色建模与修型（按脸，一次性）｜ `G` 生产（打印/材料/后处理/上色）｜ `K` 沟通确认与修改（按订单）｜ `L` 底座包装物流支付 ｜ `R` 返工报废期望 ｜ `C` 可归因获客成本。全部数值当前 `Ø`。

## 模型 I｜复用不成立（第二件 = 新建模）

- `m₁ = P − (V+G+K+L+R)`，`m₂ ≡ m₁`（同结构、同成本）
- 复购带来的是 **频次，不是毛利**。第二件唯一省下的是 `C` 和信任建立成本，不是生产成本。毛利率恒定。
- `LTV = n·m₁ − C`，门槛 `n > C/m₁`

**频次生意能覆盖低频获客成本的三个条件（须同时成立）：**

1. `m₁ > 0` 且首单不靠补贴——因为没有后端可回收；
2. **存在外部复购触发事件**（新身份、新日期、新场合）。没有触发，`n → 1`，一切归零；
3. 复购间隔短于客户记忆与联系半衰期，且短于现金周转承受期。

**这里是本轮最重的一处冲突**：条件 2 恰被决策 1 亲手削弱。毕业能产生第一单，是因为毕业是**日期**。"智者版""二次元版"不是日期、不是事件、不是场合——它只是一个审美选项。**决策 1 把复购从事件驱动改成了收藏欲驱动，而同时决策 2 又把最有事件锚的形态（换装：入职→职业装、结婚→礼服、比赛→运动姿态）推迟了。**

## 模型 II｜复用成立（第二版本免建模费）

- `m₂ = P₂ − (G+K′+L+R)`，`K′ < K`（角色已确认，沟通大幅缩短）
- 设 `V` 占首单直接成本比重为 `α`。`α` 越大，`m₂ − m₁` 越大。
- 生意形态变为**剃刀-刀片**：首单可低毛利甚至平价获客，利润从第二件开始。

**但模型 II 有一个自毁条款**：`α` 大意味着首单低价可行，`n≈1` 意味着首单低价必亏。**在验证 `n` 之前采用模型 II 的定价策略，是不可逆的现金损失。**

## 两套模型不取平均

它们对应两套互斥的定价与获客策略（I：首单必须自负盈亏；II：可补贴首单）。**分水岭是一个数字：同一人同一批照片做第二个风格版本，建模费减免比例。** 这正是 TASK-001 档 D′ 问题 9 要问的那个数。

**另需指出**：决策 1 把复购定义为"人格版本"，而人格版本改的正是造型本身（脸型气质、姿态、服装、配色）。**最不可能复用的形态被定为核心复购，最可能复用的形态（换装，同一角色资产换外层）被推迟。** 这不是执行细节，是模型 I 与模型 II 的选择被决策本身预先推向了 I。

# 二、产品单位变更的商业后果

## 2.1 谁发起、谁付款、按人还是按单

|      | 一件群体作品                     | 每人一件独立人偶                                             |
| ---- | -------------------------------- | ------------------------------------------------------------ |
| 发起 | 必须有组织者，且组织者拥有决策权 | 组织者从**策划者**降为**传播者**，动机同时消失（他不再拥有那件共同作品） |
| 付款 | 一笔（代付或 AA）                | n 笔独立付款；无收钱、无坏账、无退出纠纷                     |
| 计价 | 尚待验证的"关系构图"单位         | **按人**——与 WishFigure `N×单价`、Figure Bobblehead、易模完全一致 |

**最大代价**：竞品分析已列出 PPSB 没有的七项差异化。当时唯一未被放弃的一格是"一件关系作品与每人单件之间的新计价单位"。决策 3 主动放弃了这一格。**产品单位变更后，PPSB 与现有真人卡通定制商家的计价结构完全相同，差异只剩风格与运营。**

## 2.2 宿舍/实验室团购：履约变强，转化变弱

- **变强**：4 件独立 SKU，生产标准化，无多人构图费，包装标准化，任一人退出不影响其余人（订单从 all-or-nothing 变为可分割）。这是决策 3 真实的收益。
- **变弱**：从"一次群体决策"变为"n 次个人决策"，失去"必须凑齐"的社会压力。
- **关键读数**：CAC 摊薄能力 = **群内渗透率的函数**。一次进群若成 2–3 单，摊薄优于群体作品；若只成 1 单，退化为纯个人零售、CAC 全额压单。这个数可以在花任何生产费之前测。

## 2.3 客单价与订单额

- 客单价（per-order）↓：从整组价降为单件价。
- 订单额（per-group）：视渗透率而定，方向不定。
- **真正的变化不在数值，在心理账户**：从"仪式纪念品/礼物"账户滑入"潮玩单体"账户。前者对标毕业写真、纪念册、礼物交换，价格带高、比较对象弱；后者对标泡泡玛特、Jellycat、谷子，价格带低、比较对象是成熟 IP。**决策 3 把价格天花板从礼物带下移到玩具带。**

## 2.4 "系列化收藏自己"最接近的可比对象

| 对象                     | 同位程度                                           | 读数                                                         |
| ------------------------ | -------------------------------------------------- | ------------------------------------------------------------ |
| **Funko Pop! Yourself**  | 最高：模板化统一美感＋身份线索＋单体收藏＋批量礼券 | 但它寄生在 Funko 已有的品类心智与渠道上；Funko 母公司 2025 仍亏损，Pop! Yourself 收入未单列 |
| **Hero Forge**           | 最接近"一个角色资产反复变化、跨数字与实体购买"     | 角色是虚构桌游角色，不是真人身份；驱动来自玩桌游这一高频使用场景 |
| **Bitmoji 官方实体周边** | **最相关的反面同位**                               | 拥有日均 3.2 亿人使用的自我形象资产，实体周边仍已停止。这是"收藏自己→实体化"目前最强的负面信号，且它此前只被列在墓碑表里，没有被用来评价本路线 |

**它是什么生意**：形式上是消费品生意，成本结构上是服务生意。**当前决策组合让它卖消费品的价格，扛服务的成本。**

更硬的一点：泡泡玛特的收藏驱动来自**稀缺性 + 社群共识 + 二级市场**三件事。"收藏自己"三件全无——自己不稀缺、无人与你共识、没有二级市场。**借用了泡泡玛特的形式，缺失其全部驱动机制。**

## 2.5 放弃换装与配件，供应链简化值多少

| 项目         | 实际免掉多少                                                 |
| ------------ | ------------------------------------------------------------ |
| **SKU**      | 真省。每套服装＝独立模型＋适配测试；配件＝独立小件（打印/组装/上色/质检/分格包装） |
| **模具**     | **≈ 0**。按件 3D 打印路线本就无模具，模具只存在于注塑量产。省的是距离极远的未来开模费，不是当期成本 |
| **库存**     | **接近 0**。按单打印无成品库存；仅当配件走采购件（学士帽、书本、道具）才有 MOQ 备货 |
| **协调成本** | **真省，且是主要收益**。选项减少→沟通轮次↓、修改轮次↓、返工判定复杂度↓、报价口径可比性↑ |

**结论**：简化的价值几乎全部落在人工与沟通，不落在资本与库存。价值量 `Ø`，可在首件样品账本中直接测出。 **但这笔交易的净值可能为负**：换装是资产复用最强、边际成本最低的复购形态。推迟换装＝推迟了唯一可能带来高毛利复购的产品线，换来的是一笔当期沟通工时的节省。

## 2.6 统一美感与风格审美能力

- **杨当前是否具备：`Ø`**。仓内没有任何材料证明杨或团队完成过一件人偶或一套统一风格的角色设计。KAIROS 证明的是叙事与语言判断力，**叙事审美不可迁移为造型审美**。
- **可招聘/可外包/愿望**：当前是愿望（`H`）。按前轮已裁定的分层，"现在没有"不写成"不可得"。
- **但本路线改变了这项能力的性质**：单体没有关系叙事托底，用户唯一买的就是"好看且是我"。审美从"交付质量的一部分"升级为**产品定义本身**。外包审美＝外包产品定义权。
- 与 KAIROS 同构的红旗：**审美判断能否被第二个人复现，此处连 n=1 都不成立。**
- 成本：`Ø`。取数项——能定统一风格的角色设计师的市场行情（雇佣 vs 单套外包），以及"第二人复现"的验证方式。

# 三、新增与消失的死法

## 消掉或大幅减弱（4 条）

| 原死法                         | 变化                                                      |
| ------------------------------ | --------------------------------------------------------- |
| 死法1 按人线性成本 vs 群体定价 | **消掉**。按件计价，收入与成本同向。这是决策 3 最实的收益 |
| 死法2 群体协调成本             | **大幅减弱**。无需 4 人共同收敛，每人只审自己那件         |
| 死法5 追加费用与退款争议       | 减弱。选项少、规格固定、口径可比                          |
| 死法6 季节峰值压垮产线         | 减弱——但代价是**同时失去了唯一的付款触发日期**            |

## 新增（5 条）

1. **无事件锚死法**（最致命）。单体＋人格版本复购，第二次购买没有任何外部触发。毕业带来第一单，之后没有下一个日期。`n → 1`，模型 I 直接不成立。
2. **心理账户下移死法**。从纪念品带滑入潮玩带，价格天花板下降，比较对象变成泡泡玛特／谷子，而"自己"没有 IP 溢价、稀缺性与二级市场。
3. **复用假设与人格版本互斥死法**。唯一能救单位经济的资产复用，被"人格版本＝重做造型"的定义在产品层面否掉。
4. **审美即产品死法**。产品价值 100% 压在造型美感上，该能力当前 `Ø`，且不可外包（外包＝让渡产品定义权）。
5. **最后一格差异化被自愿放弃**。计价单位与在位者完全相同后，PPSB 需要用风格与运营战胜已有信任与渠道的商家——这是最难的一种打法。

## 保留

数字稿—实体一致性走样（死法3）、工具层被平台商品化（死法8）、只能成为小型工作室（死法9）。

# 四、当前档位是否改变

**未改变的：**

- 公司投入优先级：**仍无候选**。`F-M` 仍为零，本轮只改假设、未增证据。
- PPSB 整体档位：**可以验证，不可投入**。
- 行动优先级：KAIROS 仍第一（首场约访已备好、只差执行），PPSB 与其并行、互不等待。

**改变的三处：**

1. **研究优先级的理由变了，重心也变了。** 上轮的高研究优先级建立在"三档询价能拆出多人构图成本"上——决策 3 已把档 C 降为诊断项，档 B（4人4件）在单体化后信息量塌缩（必然≈4×A，除非有批量折扣）。**五档实际塌缩为 A 与 D′。** 研究优先级仍高，但价值高度集中在 D′ 一档。
2. **形态 B（身份品牌）的依据变弱。** 它原本寄生于 A 的复购数据；现在复购被定义成最不可复用的形态，B 的路径比上轮更窄。
3. **与杨既有资产的重叠度下降。** 原"关系实体化"与 KAIROS 在关系判断、语言采集、共创上部分同构；改为泡泡玛特式单体后，所需核心能力变为造型审美＋潮玩渠道，与杨的活体网络（商协会、中年企业主）与已验能力当前不重叠。**这是状态读数，不是结构判定**（上轮"结构性错配"已撤回，本轮不复用该定性）；可建设性仍为 `H`。

**与其余方向的同尺排序：不变。** AI 价值计量（Paid 系）、销售前置引擎、Spangle／跨境 DTC 的 SK 侧获客机制仍全 `Ø`；无任何方向出现 `F-M`。本轮无理由重排。

# 五、一个最便宜的下一步

**把阶段 B 首轮从五档缩为两档（A ＋ D′），附一份《人格版本规格书》，先发一家。**

理由：

- D′ 的答案（第二版本建模费减免比例）是模型 I 与模型 II 的**唯一分水岭**，其余三档在决策 3 之后已不再回答主线问题；
- A 是 D′ 的分母，必须同时问；
- 《人格版本规格书》必须先写——"智者版"到底改脸型、改姿态、改服装还是只改配色与材质，不写死，D′ 的报价不可读。**而且这份规格书本身零成本、且会立刻暴露矛盾**：改得越多越不可复用，改得越少越不构成"不同人格"。

这一步不需要新增预算，不需要样品，不需要渠道，只需要杨的阶段 B 授权。
