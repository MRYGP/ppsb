# PPSB｜竞品结构分析

> 日期：2026-08-06  
> 性质：有界竞品研究，不是创业立项结论  
> 边界：只使用当前公开页面与外部评价；未联系、未购买、未登录私人账号。挂牌价、站内案例和评价数量均不等于真实收入或利润。

## 零、产品口径校正

PPSB 当前研究的不是易模式“真人写实复刻”，而是：

> **以真人为原型，提取熟人可识别的身份线索，把人角色化、卡通化，再做成统一风格的实体玩偶。**

身份线索可以来自发型、眼镜、脸部特征、服装、姿势、爱好和标志性物件；验收标准是“熟人认得出是谁、整组放在一起有统一美感”，不是追求皮肤纹理或一比一脸部复刻。

照片卡通化和卡通头像已经是成熟能力，本轮不再把“能否卡通化”列为核心技术风险。它只作为产品基础规格。真正待验的是：客户是否愿为自己的实体角色付款、多人订单能否成立、以及同一角色能否形成后续换服装／动作／场景／载体的再次购买。后两项当前均为 `H/Ø`。

## 一、结论先行

PPSB 面对的不是空白市场，而是一个已经分层的“真人原型角色化＋实体交付”市场：

1. 低价平台已能把一张照片变成卡通形象并交付多种实物；
2. 中高价工作室已能按真人身份线索制作 chibi、摇头公仔和风格化收藏人偶；
3. 家庭、情侣、婚礼、毕业和团队场景已经被多个商家覆盖；
4. 现有玩家大多把多人作品按“每个人一份定制雕塑”计价，而不是单独出售“关系结构”；
5. 暂未看到谁把群体构思、多人共同审核、组织者发起、群体付款与统一交付做成完整产品。

因此，PPSB 不能再把“多人”“毕业”“照片变实体”本身当差异化。当前仅剩的待验空隙是：**能否把一群人的共同关系与共同决策，组织成比普通多人定制更省事、更确定、更愿意付款的产品。**这是 `H`，不是已证明机会。

### 第三层｜相邻但不可直接同尺

- [速哇 3D 摄影](https://www.suwa3d.com/about-us.html)：影棚／扫描、门店和活动入口，获客与数据采集结构不同；可研究交付和活动渠道，不能拿门店死活直接证明照片共创模式。
- [Popzao](https://popzao.com/)：面向 IP 与批量潮玩制造，公开示例以大批量打样量产为主；它是未来的履约或复制威胁，不是当前一件起订的直接竞品。
- 软陶／手工定制：按师傅手艺交付，能抢低价情感礼物需求，但产能、标准化和线上预览结构不同。
- 毕业照、相册、亚克力摆件、冰箱贴：不是同形态，却争夺同一笔毕业纪念预算；从客户视角看，它们可能比 3D 人偶更直接。

## 三、活体竞品真正靠什么生存

当前公开材料只能观察机制，不能证明利润。

| 生存机制 | 外部可观察证据 | PPSB 含义 |
|---|---|---|
| 按人收费 | WishFigure 明确情侣、家庭均按人数乘单价 | 多人不天然带来规模经济；共享场景也可能仍是 per-face 成本 |
| 先付款再设计 | WishFigure 先结算后提交照片；My3DSelfie 也是定制订单流程 | 可减少无效设计，但把信任、退款与预期管理推到前台 |
| 预览和修改闸门 | WishFigure 1 次免费修改；Figuro 用 AI 预览并允许人工接管 | 修改次数是单位经济变量，不只是服务细节 |
| 人工修型与上色 | WishFigure、UUMIXI、My3DSelfie 都保留人工环节 | AI 降低初稿成本，不等于消灭人工判断与返工 |
| 用场景页获客 | 婚礼、家庭、宠物纪念、毕业分别有落地页 | 场景化能降低理解成本，但容易被所有商家复制 |
| 从单品扩展同一形象周边 | AnyMade 将一个形象扩为手办、挂件、冰箱贴等 | 复购可能来自“同形象多载体”，不一定来自再做一套新人偶 |
| 礼盒与期限 | WishFigure 单独售礼盒并写明制作周期 | 产品价值包含交付时点和揭晓体验，不只是模型本身 |

## 四、PPSB 当前没有的差异化

以下均已被竞品覆盖，不能再写成“无人做”：

- 照片生成 Q 版形象；
- 生成后实体打印；
- 情侣、家庭、好友、毕业和团队场景；
- 多人共享场景或共享底座；
- 下单前预览与修改；
- 礼盒与纪念叙事；
- AI 初稿加人工精修。

“卡通化后仍能被熟人认出”也不能写成独家能力。WishFigure、摇头公仔商家和大量数字头像产品已经把发型、脸型、服装、姿势和标志物用于身份保持。PPSB 可以把它做得更好，但不能把这一基础能力当作市场空位。

## 五、PPSB 可能存在但尚未证明的空隙

| 可能空隙 | 当前证据 | 最便宜验证 |
|---|---|---|
| 群体共同构思，而非买家替所有人决定 | `Ø` | 观察一次四人共同选择模板、动作和关系元素的过程 |
| 群体审核与版本共识工具 | `Ø` | 不开发软件，先用群聊＋两版图测试能否收敛 |
| 由宿舍／实验室组织者发起的团体订单 | `Ø` | 找一名真实组织者承担一次引荐或展示动作 |
| 一件关系作品与每人单件之间的新计价单位 | `H` | A/B/C 同商家询价＋客户价格访谈 |
| 截止日期确定的毕业交付 | `Ø` | 供应商书面确认交期、延误和返工责任 |
| 一次关系设计生成多种实物载体 | 竞品已有局部结构，PPSB 是否更好 `Ø` | 同一组图只展示人偶与低价平面载体，观察客户选择和付款 |
| 同一真人角色持续换服装、动作、场景或关系组合 | `Ø`；目前只是产品设想 | 首单后只展示一个明确的第二款方案，观察是否有人愿意再次付费，不用“你以后会买吗”代替行为 |

这里没有“生态位已成立”。只有六个可以被行为快速推翻的假设。

## 六、竞争上的最大威胁

1. **低价平台吞掉工具层**：AnyMade、创客贴已经把照片生成与下单连起来；PPSB 自建生成器很可能只是在重复功能。
2. **高端工作室占据信任层**：WishFigure、Wackelwelt 等玩家用人工精修、预览、礼盒和售后管理“角色是否像这个人”的预期。
3. **多人并不构成空位**：Figuro、WishFigure、Mini Mate 及多家摇头公仔商家已支持情侣、家庭和群组。
4. **毕业不是独占入口**：易模和多个海外商家已把毕业作为场景；摄影师、相册和普通礼品仍占据预算。
5. **供应链容易复制前端创意**：若 PPSB 不能拥有组织者渠道、群体工作流或真实关系数据，工厂和现有平台都能复制模板。
6. **产品可能退化为项目服务**：每组关系都要杨或设计师重新判断，天花板就是定制工作室，而非规模产品。

## 七、当前竞争裁决

PPSB-A 仍值得进入询价和样品阶段，但理由已经改变：

- 不是因为竞品少；
- 不是因为没人做多人或毕业；
- 而是因为可以用较低成本检验“群体关系工作流”是否比普通多人定制更有价值。

卡通角色化的基础技术不再需要单独论证。若客户只在意“认不认得出、多少钱、多久到”，PPSB 将直接落入现有定制公仔市场；若客户愿意为共同构思、群体审核、组织者服务、确定性交付或同一角色的后续变化承担价格或行为成本，才可能形成新的产品单位。

## 八、仍缺的证据

- 中国竞品真实成交、退款、复购与获客成本；
- 四人群体作品的可比报价；
- 毕业组织者是否愿意发起；
- 客户究竟买“一件共同关系作品”还是“每人自己的单人版本”；
- 群体共同审核是乐趣还是负担；
- 真实样品与屏幕预览之间的满意度落差。
- 同一角色的第二次购买究竟来自真实需求，还是只存在于产品推演。
