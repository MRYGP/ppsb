## 一、Claude 的核心纠正

Claude 指出，TASK-003 阶段 C 中的「单人」是人物数量，不是件数。因此「单人」与「同一人物复制 N 件」可以同时成立。真实缺口是阶段 C 没有登记复制件数 N、每件与订单总价、接收者数量和分送方式。

Claude 建议不将单件与 N 件预先拆成两组，而将 N 作为付款人在看到单件价、阶梯价与订单总价后的选择结果。该建议为 I，尚未裁决。

Codex 初步读盘确认：TASK-003 的原文确实只写「单人」，没有写「单件」；此前讨论稿将其解读为单人单件，是误读，应在后续修订时纠正。

## 二、Claude 认为成立的缺口

### 1. 五角色未完全进入试验字段

Claude 指出「长期接触者」只在五角色结构文件中定义，TASK-003 阶段 C 字段和赠礼讨论稿的最小记录表均未登记。其建议是登记接收者之外、日常同处一个空间的室友、同事或家人，以及他们是否知情和有无反应。

Claude 还建议增加付款人交付后的反应，例如主动提及、后悔、尴尬或新节点订单。该项不是付款或复购证据，但可解释付款人一侧的后续行为。

Codex 初步读盘确认：长期接触者缺字段为事实。付款人事后行为目前也无字段。

### 2. 升级门未覆盖 N 件单位

Claude 指出可行性分析报告 9.1 的最小闭环表只写付款人、赠送对象、接收者、摆放决定和两周后，未登记 N、订单总价或逐位接收者。由于当前唯一在验产品单位是同一人物复制 N 件，该升级门可能被较小范围的事实误用来升级 N 件假设。

Codex 初步读盘确认：该表没有 N 与逐位接收者字段。这是 F-P 的文件口径缺口。

### 3. 共创参与者与实习关系

Claude 认为固定报酬能降低一次性参与者的客气压力，但同一人兼任实习生和付费共创参与者时，持续雇佣关系可能压低批评。建议明确：共创部分的负面反馈、退出和不喜欢不进入实习评价、留用或推荐。

Claude 还指出，当前「优先女实习生」是杨为取得不同于自身的个案所作的方向选择，不可被写成性别与流程断点有已验证关联。建议候选人的主要筛选顺序回到是否未做过同类定制、能否具体表达负面意见和是否愿意保留过程记录。

Codex 初步读盘确认：允许同一人兼任为事实，当前没有写明反馈与实习评价隔离。性别与流程断点关联没有仓库材料。

### 4. 肖像、样品和退出边界

Claude 指出当前尚未明写：样品实体归属；人脸数据和 3D 文件的保存期限与删除机制；样品照片可提供给供应商、内部留档或合作方的边界；未成年参与者的处理。上述均为待补的流程与隐私边界，不构成需求判断。

Codex 初步读盘确认：招募设计稿没有覆盖这些项目。

### 5. 球友线的排序前提

Claude 指出「离开者购买自己的 N 件送球友」是一个待确认是否存在的订单，而非当前事实。球友可及性也可能来自杨的直接关系，因而付款未必构成独立 F-M。建议将球友线从「最快得到独立付款」改为「较容易同时观察多个角色的候选试验」，并在接触前登记付款人与杨的关系及真实赠送节点。

Codex 初步读盘确认：当前讨论稿对节点存在与付款人独立性写得不够前置；球友线的排序只能保留为 I 级建议。

## 三、Claude 提出的新增假设和反向线索

以下均非仓库既有事实：

1. 接收者在公共可见空间摆放付款人形象，会向第三方公开二者关系；其成本可能高于工艺质量。该假设为 H，须以实际接收者行为验证。
2. 实习生身份可能抑制批评。该为 I 级常识性推断，尚无 PPSB 针对性材料。
3. 博主可能为视频内容而自费购买自己的实体。该为 H，不能把这种购买等同于关系赠礼。

Claude 还建议将 Funko 和 Hero Forge 把最终身份选择权交回接收者，单列为 I 级待检反向信号：两者的公开机制不同于「复制付款人形象分送多人」，但这不能证明其刻意回避或否定 PPSB 的结构。

## 五、Codex 的初步复核与保留意见

- 「单人」不等于「单件」的纠正成立。后续应补字段，不应无证据拆成两组试验。
- STATUS.md 的最后写入时间早于本轮讨论稿是事实。AGENTS.md 并未要求每一份研究讨论稿都进入 STATUS；但如果把某项讨论转化为正式任务或已核验结论，届时必须更新相应状态。
- Funko 和 Hero Forge 的身份选择机制是有价值的待检反向线索，不能直接升级为「规模化玩家都在回避 PPSB」的结论。
- 未成年参与者、数据删除、肖像授权可能涉及适用法律和实际合同关系。仓库可先建立保守流程边界；若实际招募未成年人或对外处理肖像数据，需另行取得适当专业意见。

## 六、保持为 Ø 的问题

- 接收者是否愿意在他人可见的空间摆放付款人的形象；
- 是否存在可独立核验的「付款人形象复制多件并分送多人」规模化产品；
- 球友线近期是否有真实、非人为制造的赠送节点；
- 首次试验由谁跟踪接收者、接收者是否同意被跟踪；
- 参与者是否会为自己的样品付款，B2 不能回答；
- 付款人交付后是否产生后悔、尴尬或再次购买。
